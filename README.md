# 骰子派对 🎲

一个为亲子桌游准备的轻量掷骰子网页。选择 1–6 颗骰子，点击投掷，约两秒的立体翻滚动画后显示每颗顶面点数与总和。采用俯视视角，顶部为最清楚的可见面，投掷结果以顶面为准。

支持手机和电脑、音效开关、空格键投掷、最近 8 次记录以及减少动态效果偏好。设置和记录仅保存在当前浏览器，无需登录。点数通过浏览器 Crypto API 生成，拒绝取模偏差；每颗骰子独立取 1–6 的整数。

展开“给骰子穿新衣”可以自定义骰子背景：一张照片铺满所有面，或为 1–6 点面分别选择照片，也支持一次选择六张后逐面更换。照片背景应用到全部骰子，点数保持可见。原色模式保留选好的照片，清除按钮会恢复原色并删除浏览器中保存的照片副本。

照片在设备上居中裁剪为 512×512 JPEG，只保存在当前浏览器的 IndexedDB 中，不会上传。支持浏览器可解码的常见图片格式，每张上限 20 MB；无法解码的照片会提示更换格式。切换设备或清除网站数据后需重新选图。

## 本地运行

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

## 验证与构建

```sh
npm test
npm run build
npm run preview
```

生产文件输出至 `dist/`，使用相对资源路径，可部署到 GitHub Pages 或任意静态网页托管服务。字体使用设备自带的中文字体；骰子、动画、声音均无外部素材依赖，打开页面不需要第三方字体或媒体服务。

## GitHub Pages

仓库包含 `.github/workflows/deploy.yml`，推送到 `main` 后会运行测试、构建并部署。

在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。随后推送或在 Actions 页面手动运行部署工作流。
