# 随机1-6 · 微信小游戏

这是原生微信小游戏：入口为 `game.js` 和 `game.json`，使用微信 Canvas 2D 绘制界面。项目不需要网页容器、后端服务或云开发。整个仓库根目录的 `project.config.json` 已配置为小游戏，代码目录为 `minigame/`。

支持 1–6 颗骰子、约两秒立体翻滚、顶面计点、音效、撒花、最近八次记录，以及一张照片铺满六面或分别设置六个面的背景。投掷结果直接看骰子顶面，不再额外显示点数标签或结果卡。手机上上下滑动可查看照片设置和历史记录。

## 1. 用小游戏账号导入

1. 安装并登录微信开发者工具稳定版，登录微信须有该小游戏的开发权限。
2. 如果之前打开过本仓库的小程序版本，先关闭那个项目窗口，再重新导入。
3. 项目目录选择包含 `project.config.json` 的整个 `dice` 目录；使用下载包时，选择解压后包含此文件的那层目录。
4. 使用自己的 **微信小游戏 AppID**。本地配置保留了当前账号的 AppID；换账号时在导入界面修改。
5. 确认项目为小游戏，点击“编译”。不需要“构建 npm”，不需要开通云开发。
6. 基础库选择较新稳定版，照片隐私授权需要至少 **2.32.3**。

当前配置的关键字段是 `compileType: "game"` 与 `miniprogramRoot: "minigame/"`。小游戏入口在 `minigame/game.js`，配置在 `minigame/game.json`。如果仍报找不到 `miniprogram/game.json`，说明开发者工具还在使用旧项目目录或旧配置，请关闭项目重新导入。

## 2. 完善后台资料

登录 [微信公众平台](https://mp.weixin.qq.com/)，进入这个小游戏账号。

- 小游戏画面、分享标题和后台账号名称统一使用“随机1-6”，避免审核时出现名称不一致。
- 简介参考：“用于亲子桌游的掷骰子小游戏，支持多颗骰子、立体动画和自定义六面照片背景。”
- 头像可使用包内 `minigame/assets/avatar.png`，为 144×144 PNG；如果当前后台要求其他尺寸，以后台为准。
- 游戏截图应来自实际手机或模拟器运行画面，头像不能替代功能截图。
- 按账号与类目要求完成主体资料、认证、资质审核和小游戏备案。可选资质与办理时间以该账号后台为准。

## 3. 配置相册的隐私指引

小游戏后台需要两项配置：

1. 在《用户隐私保护指引》中如实声明接口要求的“选中的照片或视频信息”，用途为选择照片设置骰子背景；实际代码仅允许选图片。
2. 在 **基本设置 → 隐私授权弹窗** 中开启微信官方隐私授权弹窗。使用平台弹窗需要后台配置生效；代码不会用普通确认弹窗替代隐私授权。

用途说明参考：

> 为实现自定义骰子背景功能，在您主动选择图片时，小游戏会读取您选中的照片，并在当前设备内保存和展示。照片不会上传至开发者服务器。您可以通过“恢复原色并清除照片”删除小游戏保存的照片副本，不影响手机相册原图。

填写真实的开发者联系方式。小游戏会在用户选择照片前调用微信官方隐私授权接口；取消或拒绝后仍然可以正常掷骰子。

## 4. 手机预览

点击开发者工具“预览”，用有权限的微信扫码。逐项确认：

- 1～6 颗骰子均可连续投掷；动画约两秒，结果以骰子顶面为准，历史记录与顶面一致。
- 打开音效会立即试听；调高手机媒体音量，确认翻滚和落地均有声音。iPhone 静音模式下仍可通过游戏内音效开关控制播放。
- 关闭音效或投掷中切出微信会停止声音，回来后不会出现迟到的结果或继续播放声音。
- 上下滑动可访问全部控件，小屏手机不会遮住投掷按钮或微信胶囊按钮。
- 一张照片铺六面、一次选择六张、逐面更换，都能显示并在重新打开后恢复。
- 取消选图或拒绝隐私授权不会破坏之前的背景。
- 清除照片只删除游戏保存的副本，系统相册原图保留。

浏览器中的 Canvas 预览用于检查绘图和交互，不能代替微信真机测试，尤其是照片授权、文件存储、声音和不同手机的渲染表现。

## 5. 上传、审核与发布

1. 手机测试正常后，点击开发者工具“上传”。本次名称修复版本为 `1.1.2`。
2. 版本备注参考：“按审核要求将游戏画面及分享标题统一为账号名称‘随机1-6’。”
3. 登录微信公众平台 → 版本管理，找到刚上传的开发版本。可先设为体验版并添加家人作为体验成员。
4. 点击“提交审核”，如实填写玩法、类目、截图与后台要求的资料。小游戏没有小程序页面路径，不需要填写 `pages/index/index`。
5. 确认版本审核、备案和后台要求的其他审核均已完成，再按后台提示正式发布。上传成功不代表已经上线。

审核测试说明参考：

> 进入游戏后选择 1～6 颗骰子，点击“掷出好运”，约两秒后骰子停下，以顶面点数为结果。向下滑动并展开“给骰子穿新衣”可设置单张或六面照片背景。游戏不需要登录，所选照片仅保存在当前设备。

GitHub 的自动部署只更新网页版。小游戏更新需要重新上传、审核、发布。

## 技术与验证

- 点数优先使用小游戏支持的 `wx.getUserCryptoManager().getRandomValues()`。接口缺失、异常、返回异常或 500 毫秒内未完成时，为每颗骰子独立使用本地随机数，避免游戏中断。
- 用三维旋转和 Canvas 投影绘制骰子；每个编号面对应自己的照片，最终上方的面就是结果面。
- 照片优先使用 `wx.chooseMedia`，仅允许相册图片并请求微信压缩；旧版本可兼容 `wx.chooseImage`。每张上限 20 MB，没有额外保证压缩后像素尺寸。
- 照片副本保存在 `USER_DATA_PATH/dice-party-game-photos`，不上传服务器。新文件准备及设置保存成功后再清理旧文件；失败时保留原设置。
- 配置和最近八次投掷保存在本机。更换设备、卸载或清除微信相关数据后不保证保留。
- 项目根目录执行 `npm test`。网页版仍可使用 `npm run dev` 和 `npm run build`。
